# 🦋 ТиреоГид — Интерактивный скрининг здоровья щитовидной железы

**ТиреоГид** — это информационный веб-сервис для быстрой и понятной оценки симптомов и рисков развития заболеваний щитовидной железы (гипотиреоза и гипертиреоза). Проект создан на основе принципов доказательной медицины и предлагает пользователю пройти тест за 5–7 минут.

> ⚠️ **Дисклеймер:** Данное приложение носит исключительно информационный характер и не заменяет полноценную консультацию врача-эндокринолога или лабораторную диагностику.

---

## 🛠 Технологический стек

Проект разработан с использованием актуального стека веб-разработки:

* **Фреймворк:** [React 19](https://react.dev/)
* **Язык:** [TypeScript](https://www.typescriptlang.org/)
* **Сборщик:** [Vite 7](https://vitejs.dev/) + `vite-plugin-singlefile`
* **Стилизация:** [Tailwind CSS v4](https://tailwindcss.com/) (`@tailwindcss/vite`)
* **Иконки и Анимации:** [Lucide React](https://lucide.dev/), [Framer Motion](https://www.framer.com/motion/)
